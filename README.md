
# JamAI Chat

This is a JamAI Chat project - a beautiful, modern Jamaican Patois chatbot built with React, TypeScript, and Tailwind CSS.

## Project Description

JamAI Chat is an interactive AI chatbot that communicates in authentic Jamaican Patois. The application features:

- **Modern UI Design**: Sleek, glass-morphism interface with Jamaican flag colors (gold, green, black)
- **Cultural Authenticity**: AI responses in genuine Jamaican Patois with cultural knowledge about Jamaica
- **Interactive Features**:
  - Suggestion-based conversations about Jamaican culture, food, music, and places
  - Recipe sharing for traditional Jamaican dishes
  - Patois language lessons
  - Cultural information about Jamaica
- **Responsive Design**: Modern chat interface with smooth animations and transitions
- **New Chat Functionality**: Reset conversations by clicking the JamAI logo

## Technology Stack

- React 18 with TypeScript
- Vite for build tooling
- Tailwind CSS for styling
- Shadcn/UI component library
- Google Gemini AI for intelligent responses
- Local storage for chat history

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open your browser to `http://localhost:8080`

## Configuration

To use the AI features, you'll need to provide a Google Gemini API key when prompted. The app will guide you through this process on first use.

## Features

- Chat history with persistent storage
- Bilingual support (English and Jamaican Patois)
- Cultural suggestions and conversation starters
- Responsive design for mobile and desktop
- Modern glass-morphism UI design
