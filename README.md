
# JamAI Chat 🇯🇲

*A labor of love bringing cutting-edge AI technology to Jamaica in our native tongue*

JamAI Chat is more than just another chatbot - it's the realization of a lifelong dream to see advanced technology made accessible to Jamaicans in our own beautiful language, Jamaican Patois. This passion project was born from childhood memories of watching the rest of the world embrace technological marvels while wondering when we would have something truly our own.

## 💫 The Vision Behind JamAI

Growing up in Jamaica, I was fascinated by every technological advancement that emerged globally. From the first time I held an iPhone and spoke to Siri, I dreamed of having an AI assistant that wasn't just functional, but uniquely *Jamaican* - one that understood our culture, spoke our language, and reflected our vibrant heritage.

JamAI Chat represents years of that dream coming to fruition - an AI-powered chatbot that communicates authentically in Jamaican Patois while providing the same advanced capabilities found in global AI systems. It's about technological equity, cultural preservation, and showing the world that innovation can thrive in every language and every culture.

## 🚀 Getting Started

### Quick Setup
1. **Visit the App**: Navigate to the live application
2. **Create Account**: Sign up for free or continue as guest
3. **Start Chatting**: Begin with suggested Jamaican topics or ask anything
4. **Customize**: Set your preferences and watch JamAI learn about you

### For Developers
```bash
# Clone the repository
git clone <repository-url>
cd jamai-chat

# Install dependencies
npm install

# Start development server
npm run dev

# Open browser to http://localhost:8080
```

## 🛠️ Technology Stack

**Frontend & Experience**
- **React 18** + **TypeScript** - Modern, type-safe development
- **Vite** - Lightning-fast build tool
- **Tailwind CSS** - Utility-first styling with Jamaican theme
- **Shadcn/UI** - Beautiful, accessible components

**AI & Intelligence**
- **Google Gemini AI** - Primary AI engine for intelligent responses
- **OpenAI Integration** - Alternative AI service support
- **Custom Language Processing** - Patois detection and understanding
- **ElevenLabs** - Premium Jamaican voice synthesis
- **Advanced Memory System** - Persistent, intelligent context management

**Backend & Data**
- **Supabase** - Full backend infrastructure
- **PostgreSQL** - Robust database with real-time capabilities
- **Row Level Security** - Enterprise-grade data protection
- **Real-time Sync** - Live updates across all devices
